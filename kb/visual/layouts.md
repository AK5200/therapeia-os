# Layout library

Every slide uses exactly one layout. A layout fixes the composition, where the text sits and the text style; the Art Director only fills in the scene, people, product placement and the exact words. Each layout has a reference image in the repo `refs/` folder that is sent to the image model as a STYLE reference (layout, type style, colour grade only, never its content).
Each layout also has a NOPRODUCT line: the code uses it instead of the LAYOUT product details when the slide may not show the product ("none" = the layout needs the product, another layout is used).
To add a layout: add a section here and its image to `refs/`. List every layout in the table in art.looks (visual/art-director.md).
